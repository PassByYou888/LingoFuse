## 📌 说明

- **原生包**：可直接在目标平台上运行的编译器
- **交叉编译包**：在 x86_64 Linux 上构建，为其他平台生成代码（文件名包含 `built.on.x86_64-linux`）
- 如需构建 Lazarus 环境，请根据目标平台下载对应的 FPC 包
